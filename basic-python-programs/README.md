# Basic Python Programs

This folder contains *41 basic Python programs* for Class 12 Computer Science students.

---

## 📚 Topics Covered
- Input / Output  
- Conditional Statements (if-else)  
- Loops (for, while)  
- Number-based Programs  
- String-based Programs  

---

## 🎯 Purpose
- To help students practice basic programming concepts  
- To revise important logic for exams  
- To provide simple and easy-to-understand examples
